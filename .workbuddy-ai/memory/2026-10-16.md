## Thêm bộ giải mã script extension Vbook (AES-256-CBC) vào app

**Bối cảnh**: người dùng dán JSON `script_data` gồm 10 file `.js` đã mã hoá nhờ decode; sau đó yêu cầu *"thêm bộ giải mã vào app để giải mã những script bị mã hoá như thế này"*.

**Scheme** (suy ra từ dữ liệu, đã đối chứng bằng ca thật):
- Token `x0P1Xx` / `x0P2Xx` / `x0P3Xx` → `+` `/` `=`, mỗi token thay **đúng 1 ký tự** (kiểm chứng `độ dài − 5×số_token ≡ 0 (mod 4)` trên **10/10** file).
- Payload = Base64 của **AES-256-CBC**, IV 16 byte `0x00`, padding PKCS#7 (dấu hiệu: mọi payload chia hết cho 16, tiền tố chung rơi đúng mốc 16/32/80/256 byte).
- Key = `SHA256(MD5("com.vbook.app" + source + author) dạng hex)`.

**Mấu chốt**: ciphertext **một mình không đủ để giải mã** — key phụ thuộc `metadata.source` + `metadata.author`, hai trường này **không** nằm trong `script_data`. Ca thật: bộ 10 file khớp 100% từng ký tự với extension `hhtqvietsub` v10 (`source=https://hh3d.boats`, `author=vBook`) trong `Darkrai9x/vbook-extensions` ⇒ key `d476a9f7…292073`.

- File mới `Sources/Services/Extensions/Manager/ExtensionScriptDecoder.swift` — 226 dòng, 1 type `enum`, dùng `CommonCrypto` (**CryptoKit không có AES-CBC**, chỉ GCM/ChaChaPoly).
- **+2 dòng** móc vào `ExtensionManager.swift` sau `findMainExtensionFolder`, ở cả `install(item:packageId:)` và `installFromLocalZip(fileUrl:)` (1003 → 1005, baseline 1022).
