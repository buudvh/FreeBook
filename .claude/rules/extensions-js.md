# Extension JavaScript

> Tách từ `AGENTS.md` (1.3.959). Claude Code tự nạp file này khi đọc / sửa file khớp `paths`; agent khác phải tự đọc trước khi sửa phân hệ này.

Entrypoint mọi file JS (`search.js`, `detail.js`, `toc.js`, `chap.js`, `genre.js`, `home.js`) là hàm `execute(...)`, gọi qua `runAsync`. Script nằm ở gốc extension hoặc trong `src/`. Manifest là `plugin.json`. Trên máy, tiện ích đã cài là **một file** `extensions/js/<packageId>.json` (gom lúc cài, kho ngoài vẫn phát zip): đọc script/manifest/icon qua `ExtensionPackageReader` (`scriptData(named:)` = gốc rồi `src/`, đúng hợp đồng `load()`), không ghép đường dẫn vào `localPath`.

**Kiến trúc bridge cần hiểu trước khi thêm API JS**: `JSExecutor` không expose Swift trực tiếp cho script. Nó cài các block Swift tên `_nativeXxx` (`_nativeSyncFetch`, `_nativeBrowserLaunch`, `_nativeQtTranslate`, `_nativeStorageGet`…) rồi `evaluateScript` các gói polyfill JS (`responseBootstrap`, `fetchBootstrap`, `engineBootstrap`, `qtBootstrap`, `storageBootstrap`, `userAgentBootstrap`, `scriptBootstrap`) dựng nên API mà extension thấy: `Html`, `Engine`, `Response`, `fetch`, `Qt`, `Crypto`, `Script`, `UserAgent`, `localStorage`, `cacheStorage`, `localConfig`, `localCookie`, `console`/`Console`/`print`/`Log`, `toast`, `load`, `atob`/`btoa`. Thêm một API JS = thêm cả block `_native*` **và** wrapper trong bootstrap tương ứng. Đừng phá tương thích ngược nếu không được yêu cầu.

**`load('x.js')` = thay văn bản trước khi chạy** (hợp đồng, 1.3.657): `prepareScript` chạy trước các file mà script chính `load(...)` ở **cột 0**, rồi mới chạy script chính ⇒ khai báo của script chính thắng khi trùng tên (`config.js` có `execute()` riêng không đè `execute()` của script). `load` cùng tên sau đó là no-op; `load` runtime file chưa nạp (`Script.execute`, `Qt.include`) giữ kiểu chạy ngay. Code ở `JSExecutor+Load`. Tiện ích không mang file mà tên nằm trong `JSBuiltInLibrary` (`crypto.js` = CryptoJS 4.2.0 đóng gói, 1.3.664) ⇒ app cấp bản dựng sẵn; file của tiện ích **luôn thắng** (người dùng chọn, khác hợp đồng); sau mỗi lần nạp `crypto.js` gắn `AES.encryptGcm/decryptGcm` + PBKDF2 native (`JSCryptoJSBridge`). Detail đọc cả `comment` (một nguồn, hiện trước) lẫn `comments`; thiếu `title` ⇒ "Bình luận". Mỗi bình luận đọc thêm `avatar` (resolve như bìa) và `replies` (hợp đồng: mảng cùng dạng, lồng nhau; app dàn phẳng một cấp, xổ tại chỗ ở `CommentRowView` → `CommentRepliesBlock`); khoá riêng của Tàng Công Các `reply_source: {input, script}` + `reply_count` = trả lời tải khi bấm, chỉ dùng khi `replies` rỗng (1.3.680).

Mỗi tác vụ bóc tách tạo `JSExecutor` mới rồi giải phóng — **không** dùng executor dùng chung (`sharedExecutor` là anti-pattern có tên trong `rules.md`). Ngoại lệ duy nhất: `ExtTTSRuntime` actor được giữ executor lâu dài. `DownloadManager` mặc định dùng đúng một `BookDownloadWorker` actor cho mỗi tác vụ, tuần tự và cancel được; nguồn được người dùng chọn 2–3 luồng (`DownloadSpeedSettings`, nhớ theo nguồn, 1.3.624) thì mỗi luồng một worker riêng (`DownloadManager+ChapterLanes`), kết quả vẫn xếp đúng thứ tự mục lục.

**`fetch` lỗi tự thử lại bằng browser ẩn** (1.3.613, `JSExecutor+FetchBrowserFallback` → `HiddenBrowserFetch`): chỉ khi lỗi mạng / hết giờ / HTTP 403, 429, 503, request GET không body, URL http(s), không phải domain bị chặn, không huỷ, và **không ở main thread** (semaphore + main queue sẽ deadlock ⇒ bỏ qua). Browser ẩn chờ tối đa 15s qua trang chặn Cloudflare, đọc lỗi điều hướng + mã HTTP trang chính (`WebViewLoader+NavigationResponse`). Thành công ⇒ trả 200 cho script; cả hai lỗi ⇒ giữ response gốc, `statusText` = `"<gốc> | Browser ẩn: <lý do>"`. Executor cần dữ liệu nhị phân tắt bằng `allowsFetchBrowserFallback = false` (`ExtTTSRuntime`, `ComicImageScriptRunner`). Cookie qua thử thách nằm trong kho WebKit, **không** sang URLSession.

**Nút "Mở link lỗi"** (1.3.614): executor ghi URL fetch lỗi / fetch gần nhất của lượt chạy (`JSExecutor+FetchTrace`, xoá ở `beginExecution()`; tên miền chặn sẵn không ghi); `ExtensionManager` bọc lỗi của 10 hàm chạy script bằng `ExtensionLoadError` (chữ lỗi giữ nguyên — so kiểu lỗi gốc thì `ExtensionLoadError.unwrapped(_:)`). Màn lỗi dựng link bằng `SourceErrorLink.resolve(from:fallback(s):host:)` **ngay trong `catch`** (fetch lỗi → fetch gần nhất → URL lỗi Legado → URL đầu vào), hiện `ErrorLinkCaption` + `ErrorLinkButton`, và `.errorLinkBrowser(link:onRetry:)` mở `BypassWebView(forcesMobileUserAgent: true)`; đóng ⇒ `WebKitCookieBridge` chép cookie WebKit của tên miền sang `HTTPCookieStorage.shared` ⇒ tự thử lại. Màn lỗi mới thì nối cùng kiểu này. Nút **luôn hiện** mở trang nguồn khi không lỗi (1.3.763, viên thuốc "Trình duyệt" của màn xem phim = link chi tiết của phim, không phải link tập) dùng `.sourcePageBrowser(link:packageId:)`: cùng trình duyệt, đóng ⇒ chỉ chép cookie, **không** thử lại; tách riêng với "Mở link lỗi" (link lỗi thường là `fetch` hỏng ở host API, khác trang chi tiết). Màn có dọn dẹp ở `onDisappear` (video) phải coi link đang mở là "bị trình duyệt che" như với link lỗi. Truyện chữ/tranh đã có "Mở bằng trình duyệt" ở ngăn kéo Chi tiết / Reader / sheet nhấn giữ.

**Bộ lọc theo tab** (1.3.746): nút / sheet "Bộ lọc" (`ExtensionFilterButton` / `ExtensionFilterSheet`) chỉ hiện mục `select` / công tắc / `list` của `config` mà **script của tab** nhắc tới — file đó cùng mọi file nó `load('x.js')` (đệ quy), bỏ comment, khớp nguyên tên (`ExtensionScriptConfigScanner`, quét chữ, không chạy script). Tab = `ExtensionFilterScope`: Khám phá theo tab đang chọn (Trang chủ ⇒ `explore`, Thể loại ⇒ `genre`, tab home ⇒ `script` của mục), danh sách thể loại / Xem thêm ⇒ `category.script`, Tìm một nguồn ⇒ `search`. Tab không dùng mục nào ⇒ ẩn nút. Khoá mà file dùng chung (vd `config.js` load ở mọi script) nhắc tới thì hiện ở mọi tab — quét chữ không theo luồng dữ liệu; muốn gọn thì sửa tiện ích, không sửa app. Màn danh sách mới của tiện ích gắn nút + sheet kèm `scope`.

**Báo cáo kiểm tra lưu trên máy** (1.3.759): mỗi lượt Kiểm tra tiện ích JS (`ExtensionCheckRunner`, ghi khi xong/dừng — trước đó chỉ ở RAM) và Kiểm tra nguồn Legado (`LegadoCorpusRunner`, ghi mỗi 50 nguồn + khi xong; trước đó không ai xoá) là một file, qua `CheckReportStore` (chủ duy nhất; giữ 20 bản mới nhất mỗi loại, dọn sau mỗi lần ghi + lúc mở app ở `MainTabView`; lượt đang chạy `markActive` không bị xoá, kẻo checkpoint ghi lại). Trang **Báo cáo kiểm tra** (`Views/Extensions/CheckReports/`, mở từ ngăn kéo … tab JS / Legado) đọc qua `CheckReportRepository`: danh sách, chi tiết **chỉ xem** (không chạy lại, không Tắt/Xoá nguồn lỗi; báo cáo JS không có "Mở link lỗi" vì `errorLink` không vào JSON), chia sẻ, xoá, xoá hết. Tên báo cáo = `title` mà màn kiểm tra truyền vào `start(…, title:)`; bản cũ / Debug server ⇒ "N nguồn".
